# TripTrack
## Цель работы
Сервис для путешествий, который дает пользователю возможность отметить на карте места, где он был. Также предоставляется возможность добавлению достопримечательностей для простого нахождения вариантов для путешествий

### Какую проблему решает сервис;
- Выбор куда путешествовать
- Зафиксировать места, в которых уже был

### Целевая аудитория
Граждане СНГ, 15-40 лет, регулярно путешествующие по своим странам

## Функциональные требования
- Возможность создать отметку места, которое посетил пользователь
- Возможность посмотреть места, которые посетил пользователь
- Возможность добавить метку с достопримечательностью
- Возможность посмотреть метку с достопримечательностью
- Зарегистрироваться, войти, восстановить пароль

## Нефункциональные требования
- **Производительность:** система должна обрабатывать не менее 100 запросов в секунду; время ответа для 95% запросов не должно превышать 1.5 секунд.
- **Безопасность:** доступ к персональным данным и административным функциям должен выполняться только после аутентификации и проверки прав пользователя; пароли должны храниться исключительно в зашифрованном виде, а передача данных по HTTPS.
