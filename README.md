## Функциональные требования
### Happy path
Пользователь вводит город отправления, бюждет и даты. Сервис должен вернуть несколько вариантов куда можно поехать в эти даты.

## Нефункциональные требования
- **Производительность:** система должна обрабатывать не менее 100 запросов в секунду; время ответа для 95% запросов не должно превышать 1.5 секунд.
- **Безопасность:** доступ к персональным данным и административным функциям должен выполняться только после аутентификации и проверки прав пользователя; пароли должны храниться исключительно в зашифрованном виде, а передача данных по HTTPS.

## Технологический стек
### backend
- Golang 1.26+
- http для внешнего общения
- grpc для общения между микросервисами

### infra
- Приложение упаковывается в Docker контейнеры
- Для локального развертывания используется Docker-Compose

### База данных
- Для хранения пользователей Postgres
