Консольная утилита

bootstrap-admin создаёт первоначального администратора платформы.

Выберите версию для Linux:

  • Скачать для x86-64 (amd64)
  • Скачать для ARM64

Утилита подключается к PostgreSQL напрямую и требует DATABASE_URL, данные администратора и пароль через стандартный ввод. Это не клиент REST API. База по умолчанию доступна только на компьютере с сервером.

chmod +x bootstrap-admin-linux-amd64
./bootstrap-admin-linux-amd64 --help
